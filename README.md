# Sabah Industrial Holding

وب‌سایت رسمی و واکنش‌گرای گروه صنعتی صباح، طراحی‌شده با هویت بصری صنعتی، رسمی و ممتاز.

## امکانات

- رابط فارسی و راست‌به‌چپ
- صفحه اصلی بلند و ساختاریافته
- صفحات درباره هلدینگ، شرکت‌ها، زنجیره ارزش، توانمندی‌ها، اخبار و تماس
- طراحی واکنش‌گرا برای دسکتاپ، تبلت و موبایل
- تصاویر اختصاصی صنعتی
- انیمیشن‌های ظریف با Motion
- ساختار کامپوننتی و محتوای قابل توسعه
- متادیتای SEO برای تمام صفحات

## فناوری‌ها

- Next.js
- TypeScript
- Tailwind CSS
- React
- Lucide React
- Motion
- Vazirmatn

## اجرای محلی

```bash
npm install
npm run dev
```

ساخت نسخه نهایی:

```bash
npm run build
```
